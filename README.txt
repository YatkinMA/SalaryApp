# Табель + Начисление зарплаты

Простое настольное приложение для учёта рабочего времени и расчёта зарплаты сотрудников.
Создано для Windows (готовый `.exe`), работает без установки Python и дополнительных программ.

## Возможности

- **Сотрудники** – добавление, редактирование, удаление, импорт/экспорт CSV.
- **Дневной табель** – почасовой учёт по дням месяца:
    - Отображение дней недели, подсветка выходных, чередование цветов строк.
    - Задание нормы часов за месяц.
    - Ввод обычных, сверхурочных и отработанных в выходные часов для каждого дня.
    - Сохранение, очистка, импорт/экспорт CSV.
- **Расчёт зарплаты**:
    - Автоматический расчёт по правилам:
        - Обычные часы – оплата пропорционально окладу (при недоработке) или полный оклад.
        - Сверхурочные – первые 2 часа в день ×1.5, остальные ×2.
        - Выходные – ×2.
    - Сохранение результатов в историю.
    - Просмотр истории расчётов, удаление, выгрузка CSV.
- **Хранение данных** – SQLite (один файл `salary.db`).

## Системные требования

- **Для запуска готового EXE**: Windows 7/8/10/11, 100 МБ свободного места, без дополнительных установок.
- **Для сборки из исходников**: Python 3.8+, установленные зависимости (см. `requirements.txt`).

## Установка и запуск

### 1. Готовый EXE (рекомендовано для пользователей)

Скачайте архив с программой, распакуйте в любую папку и запустите `SalarySystem.exe`.
При первом запуске автоматически создастся файл базы данных `salary.db`.

### 2. Запуск из исходников (для разработчиков)

Клонируйте репозиторий и установите зависимости:
git clone https://github.com/your-repo/salary-app.git
cd salary-app
pip install -r requirements.txt
python main.py

Примечания
При первом запуске база данных salary.db создаётся автоматически в папке с программой.

Все изменения сохраняются мгновенно (кроме ручного сохранения в дневном табеле – там нужно нажать «Сохранить все изменения»).

Для работы с CSV используйте кнопки «Выгрузить CSV» / «Загрузить CSV» на каждой вкладке.

В дневном табеле для удобства шаг изменения часов – 0.5 ч (можно мышкой или клавишами вверх/вниз).

Лицензия
Проект распространяется свободно, без ограничений.
